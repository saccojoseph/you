# Security and privacy

This repository currently contains a browser-only prototype with fictional seed data. The default demo has no real account connection and sends no personal memory to a backend. Data you enter is stored in your browser's local storage, which is not an encrypted production datastore.

Do not enter real sensitive information into a publicly hosted demo or treat this prototype as a secure personal vault.

For security reports, please open a private GitHub security advisory once this repository is published. Do not post exploitable details or real user data in a public issue.

Before a real release, the project needs a threat model, encrypted local storage, access control tests, consent records, audit logs, connector permission review, backup and deletion behavior, and independent security review.
